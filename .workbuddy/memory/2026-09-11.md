# 2026-09-11

## 为子报告页补充「返回首页」导航

- 背景：`<base>.index.html` 首页可以进入概览/图/链路/注解页，但子页面无法返回首页（只有注解分页页有 indexHref）。
- 改动：
  - `src/view/graph-html-reporter.ts` 新增 `GraphHtmlOptions.indexHref`，`graphHtmlParts(opts)` / `renderGraphHtml(graph, opts)` 支持传入；header 渲染 `.home-link`。
  - `src/view/trace-html-reporter.ts` 新增 `TraceHtmlOptions.indexHref`，同上。
  - `src/view/html-reporter.ts` 的 `renderHtmlReport` 追加第 4 个位置参数 `indexHref`，同样渲染返回入口（保持各子页一致）。
  - `src/index.ts` 统一传 `indexFileName = \`${baseName}.index.html\``（注意不是裸 `index.html`，三处默认兜底值仍是 index.html）。
- 约定：传空字符串 `''` 表示不渲染返回入口；href 用编译期 `escapeAttr` 转义（不能复用运行时脚本内的 escapeHtml）。
- 验证：`npx tsc` 通过；用 `resources/` 生成 `.tmp-verify/demo.*`，graph/trace/概览三个页面均输出 `href="demo.index.html"`。
